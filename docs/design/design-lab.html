Options window · fixed 400 × 620 · changes apply immediately

Click the preview to select a target. F11/F12 are simulated (the browser may take F11 for fullscreen; the buttons do the same). Theme: Options → General → Appearance. The UI is neutral; status is the icon + text line under the preview. Marker (approved): thin neon-green ring; other colours kept for comparison. Thin solid = tracking, dashed = holding, growing outline = searching, grey with X = lost. Searching only happens with Options → Camera → Find the target again on (off by default); with it off, a loss goes straight to Lost.
